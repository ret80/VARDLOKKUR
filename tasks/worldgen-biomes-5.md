# Мир: грунт под камнем, скорость по поверхности, переходы между биомами

Итерация 4 по замечаниям к оверворлду (3 пункта).

## 0. Замечания (вход)

1. Камень не должен менять тайл земли под собой — грунт остаётся тем,
   что соответствует биому (луг/лес/болото/снег), камень — объект сверху.
2. Скорость движения существ зависит от поверхности: дорога и каменный пол
   подземелья — коэффициент 1; трава, снег, болото замедляют.
3. Резкие переходы между биомами (снег упирается в луга жёсткой линией) —
   нужна переходная полоса.

## 1. Грунт под камнем (`tile-geom.ts`)

`drawTileBatch` при `t === Tl.ROCK` подменяет тип для отрисовки грунта на
`groundTileForBiome(map.biomes[i])`: `FOREST→FOREST`, `SWAMP→SWAMP`,
`MEADOW→MEADOW`, `SNOW→SNOW`. Серый «каменный» грунт (`0x5f6b78`) больше не
рисуется. Сам тайл остаётся `ROCK` (солид) — камень рисуется спрайтом в слое
стен как и раньше.

## 2. Скорость по поверхности (`terrain-speed.ts`)

Новый модуль `src/game/terrain-speed.ts`:

- `tileSpeedMul(t)` — множитель скорости:
  - `PATH`, `DFLOOR`, `STAIRS`, `VILLAGE` — `1`;
  - `MEADOW` — `0.9`, `SHORE` — `0.88`, `FOREST` — `0.85`;
  - `SNOW` — `0.72`, `SNOW2` — `0.68`, `GRASS` — `0.7`;
  - `SWAMP`/`DEADTREE`/`FIR` — `0.6`, `POOL` — `0.5`.
- `speedMulAt(map, x, y)` — множитель по тайлу под пиксельной точкой.

Применение (`ecs-game-loop.ts`):

- игрок: `Velocity *= speedMulAt(map, pos)` сразу после `updatePlayerInput`;
- прочие существа: в интеграции позиций множитель применяется только к
  сущностям с компонентом `Enemy` (снаряды не замедляются).

## 3. Переходы между биомами (`tile-geom.ts`)

Переход сделан **только на рендере** (логика биомов, спавны, святилища,
деревни — без изменений):

- `computeBiomeEdges(map)` — от каждого наземного биома BFS на `BIOME_BAND = 4`
  тайла; для каждой клетки считается ближайший «другой» биом и расстояние `d`.
- в `drawTileBatch` для «чистого» грунта (`SNOW/SNOW2/FOREST/SWAMP/MEADOW`) у
  стыка с вероятностью `0.5·(BAND+1−d)/BAND` рисуется грунт соседнего биома.
  Детерминированный хеш `rnd(x,y,91)` — без мерцания.

Итог: на стыке биомов образуется дизеринг-полоса шириной ~4 тайла
(50 % → 37.5% → 25% → 12.5%), снег плавно «растворяется» в лугах/лесу.
