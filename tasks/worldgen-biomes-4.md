# Мир: 4 биома, деревни у побережья, руины-центр, декор

Итерация 3 по замечаниям к генерации оверворлда.

## 0. Замечания (вход)

1. **4 биома**: равнина, лес, болото, снег. Сейчас 7 (снег, хребет, топи,
   луга, руины, пустошь).
2. **Деревни** — ближе к побережью и разбросаны по всему острову.
3. **Алтарь** — в руинах в центре; к нему так просто не подойти: препятствия и
   барьер на входе.
4. **Болото**: нечастые голые деревья + немного елей.
5. **Равнина**: трава (по принципу деревьев), высотой в половину роста игрока.

Выбор пользователя (вопрос про структуру): **«Снег-центр + 3 сектора»**.
Снежная зона — центр (там руины с алтарём), вокруг 3 сектора: равнина, лес,
болото. Хребет и пустошь убрать. Руины — только центр, не биом.

Референс травы (раскодирован из вложения): пучок колосков оливково-зелёного
цвета (#364807 / #475816 / #566727 / #6a7647), шире чем выше, ~половина роста
игрока (игрок ≈15px → трава ≈8px).

## 1. Биомы острова (`island-generator.ts`)

`Biome`-значения остаются в enum (RIDGE/WASTE/RUINS — как sentinel), но
**не генерируются**.

- `R_SNOW = 15` — радиус снежного плато в центре (было 9).
- Убрать `R_RIDGE_OUT`, `R_WASTE`, `PASS_COUNT`, `PASS_HALF`, `nearPass`,
  `buildRuins`/`stampRuins`, `ruinC`, `ridgePasses`, перевалы.
- `computeBiome`: `r < R_SNOW` → `SNOW`; иначе `sectorBiome(ang)`.
- `sectorBiome` — 3 сектора по 120°:
  - `FOREST` — 210°..330° (север);
  - `SWAMP` — 90°..210° (запад-юго-запад);
  - `MEADOW` — остальное 330°..90° (восток).
- `applyBiomesToTiles`: из 4 биомов → SNOW/FOREST/SWAMP/MEADOW; `default →
  MEADOW` (никаких MTN/RUINS/WASTE-тайлов как биомов).
- `IslandResult`: только `{ w, cx, cy }` (R1/R2/R3/ruinC/ridgePasses убрать).
- Экспорт `ISLAND_RX = 94`, `ISLAND_RY = 64` — для сэмплинга деревень у берега.
- `protectReserved` — прежний, но с новым `R_SNOW`.

## 2. Руины у алтаря (`overworld.ts` Ф2)

Кольцо обломков вокруг алтаря (r ≈ 9..14) — 60% `COLUMN` (солид), 40% `RUINS`
(проходимо). Южный сектор (~±32°) оставляем открытым — там подходит дорога и
стоит барьер (`treeAltar.y+5`). Столбы помечаем `occupied`.

`w.zones`: убрать «Руины Времени»; оставить «Священная Гряда».

## 3. Деревни у побережья (`overworld.ts` Ф2)

- Сэмплинг точек по **нормализованному радиусу эллипса**:
  `f ∈ [0.58, 0.85]`, `x = cx + cos·RX·f`, `y = cy + sin·RY·f` — прибрежное
  кольцо, разброс по углам.
- `vA` и `vB` — в **разных** биомах из {MEADOW, FOREST, SWAMP} (перемешанная
  тройка) → у каждой деревни своё святилище.
- `vR` — в третьем биоме (без святилища).
- `siteAccept`: расстояние от центра ≥ `R_SNOW + 8`; `!nearWater(8)`;
  `openRatio ≥ 0.55`; ≥16 от других площадок; ≥14 от входов подземелий.
  `plainRatio`/`isPlainsTile` убрать (деревни теперь и в лесу/топях).
- Фолбэк — прибрежный сэмплер (не `randRadial`).

## 4. Святилища — 4 (`overworld.ts` Ф2)

- `LAND_BIOMES = [SNOW, FOREST, SWAMP, MEADOW]`.
- `shrineForBiome`: `SNOW → snowShrine()`; `FOREST/SWAMP/MEADOW →
  placeInBiome(b, R_SNOW+6, 46, …, offRoad)`.
- `assignVillageShrine` — строго по биому деревни, иначе ближайшая клетка, но
  всегда **пропуская уже занятый биом** (чтобы не было двух в одном биоме).
- Итог: ровно 4 святилища, по одному на биом.

## 5. Подземелья (`overworld.ts` Ф2)

`id=1` spider → `SWAMP`; `id=0` reaper → `FOREST`; `id=2` giant → `MEADOW`.
Радиус 20..46, `dist(центр) ≥ 13`. Финальный фолбэк — скан биома
(`scanBiome`), чтобы вход точно попал в нужный биом.

## 6. Прочие якорные POI (`overworld.ts`)

Все ссылки на RIDGE/WASTE/RUINS перераспределены:

- сундуки: bow → FOREST, arrows → MEADOW, heartPiece → SWAMP ?? MEADOW;
- пьедесталы (5): MEADOW, FOREST, SWAMP, MEADOW, FOREST;
- bearSpot/mossSpot/oreSpot → SWAMP; meadSpot/amberSpot → FOREST; hornSpot →
  MEADOW; relicSpot/flowerSpot → MEADOW; stashSpot → SWAMP;
- души: MEADOW, FOREST, SWAMP;
- «Ворон-Говорун» — к руинам центра;
- зона руин убрана.

## 7. Декор (`overworld.ts` Ф7)

- **Трава** `Tl.GRASS = 26` (мировой тайл, ground-слой, проходима): на
  `MEADOW` при `v > 0.45`.
- **Болото**: `FIR` (немного, `v > 0.94`), `DEADTREE` (нечастые, `v > 0.78`),
  `POOL` (`v < 0.3`). Новые тайлы `Tl.DEADTREE = 24`, `Tl.FIR = 25` (солиды).
- Лес — как было (`TREE` при `v > 0.5`); снег-центр — как было.

## 8. Рендер и утилиты

- `types.ts`: `Tl.DEADTREE/FIR/GRASS`; `SOLID += DEADTREE, FIR`.
- `wall-geom.ts`: `TREE|DEADTREE|FIR` — один блок, `fir` определяется типом
  тайла (DEADTREE → голое, FIR → ель, TREE → вариант по `v`).
- `tile-geom.ts`: GRASS — луг + колоски (~8px, оливковые); DEADTREE/FIR —
  болотный грунт.
- `map-render-system.ts`: `WALL_TILES += DEADTREE, FIR` (зеркальный вариант).
- `tiles.ts`: цвета миникарты для новых тайлов.
- `utils.ts`: `zoneFor` и `groundTileFor` — под 4 биома.
- Дороги: `Tl.GRASS: 1` в `roadCost`/`buildRoad`.

## 9. Враги (`overworld.ts` Ф8)

`ENEMY_TABLE`/`ENEMY_QUOTA` — только FOREST/SWAMP/MEADOW
(28/24/32). Снег без врагов (священная роща).
