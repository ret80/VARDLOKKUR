# Задача 25: Восстановление косы босса Жнец (регрессия рендера)

## Проблема

После рефакторинга рендера у босса Жнеца (`reaper`, подземелье «Склеп»)
пропала коса — в руках ничего не было, модель выглядела упрощённой.

## Причина

Косу вводили в коммите `ae898d0c` (SOLID-рендер): черенок рисовался штрихом
(`moveTo/lineTo + stroke`), а лезвие — дугой (`arc + stroke`).

В коммите `01ed3fad` («Фаза 6 — DI Cleanup») этот код заменили на один
`drawPoly`-треугольник, причём в него передали **hex-число**, тогда как
`drawPoly`/`drawEllipse` ожидают объект `Color { r, g, b, a }`:

```ts
drawPoly(r, g, [...], (tint as any)(0xb9c2c9, a)); // number, не Color
```

`tint` возвращает число, поэтому `color.r/g/b` были `undefined` → цвет
становился чёрным (`NaN & 0xff = 0`), а сама фигура — вырожденным тонким
треугольником. На тёмном теле это выглядело как полное отсутствие косы.
Та же ошибка была и у полигонов тела.

## Исправление

`ReaperRenderer`:
- хелпер `col(hex, alpha)` превращает результат `tint()` в корректный `Color`;
- тело/капюшон снова рисуются правильными цветами (работает tint при
  вспышке/заморозке);
- коса восстановлена: черенок через `r.drawLine` (тёмное дерево, ширина 2)
  и **заполненный серебряный полумесяц**, построенный по исходной дуге
  (центр в острие, R=6, углы `blade+1.6 … blade+3.4`); угол лезвия
  по-прежнему зависит от состояний `wind`/`swing`/`stuck`;
- вернулось кольцо-телеграф замаха.

`primitives.ring()` — теперь реально рисует кольцо (замкнутая ломаная из
отрезков), а не залитый эллипс (был неиспользуемым и семантически неверным).

## Проверка

- `npx tsc --noEmit` — чисто.
- `vitest run` — 19/19 (добавлен `__tests__/reaper-renderer.test.ts`:
  геометрия черенка/лезвия по состояниям и корректность `Color`).
- `npm run build` — успешно.
- Визуальный превью (SVG с состояниями idle/wind/swing/stuck) подтверждает
  черенок + изогнутое серебристое лезвие.
